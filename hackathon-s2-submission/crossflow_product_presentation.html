02 / Execution modes

One architecture, three targets

PAPER

Local simulation

Approved decisions execute automatically against the paper portfolio. No real funds and no per-trade confirmation.

BITGET DEMO

Demo execution

Requires both Demo Trading and Demo Autonomy. The same final validation and reconciliation path applies.

BITGET LIVE

Live execution

Requires both Live Trading and Live Autonomy. Once explicitly enabled, approved trades do not require repeated confirmation.

The trusted server setting CROSSFLOW_EXECUTION_TARGET resolves the target. Qwen cannot change it. Environment mismatches fail closed.

03 / Decision engine

Qwen proposes; controls decide

LONG

Propose an entry when evidence supports it.

REDUCE

Reduce an existing position when conditions weaken.

CLOSE

Exit an existing position when invalidated.

WAIT

Take no action when evidence or safety is insufficient.

Qwen cannot enable autonomy, switch Paper/Demo/Live, bypass risk controls, or submit orders directly.

06 / Execution reliability

The exchange state wins

Before submission

  • Stable client order identifiers
  • Fresh account and quote validation
  • Unresolved-order and reconciliation locks
  • Duplicate prevention

When the network is uncertain

  • Unknown outcomes remain pending
  • No immediate blind retry
  • Reconciliation queries the exchange
  • Conflicting actions stay blocked

After submission

  • Requested and filled quantities tracked
  • Fees, average price, and order IDs recorded
  • Balances and positions refreshed
  • Locks release after reconciliation

Final product summary

Calculated decisions, bounded execution

CrossFlow allows AI-driven trading decisions to execute autonomously without giving the AI unrestricted control of funds or infrastructure.

Qwen handles market reasoning. Deterministic controls handle authorization. Trusted server configuration controls the execution environment. The exchange remains the source of truth for actual execution.

If execution safety cannot be established, CrossFlow fails closed.
